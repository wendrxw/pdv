Estações de impressão

Cada estação é um computador da loja com o Local Print Agent e uma impressora térmica USB. Crie a estação, copie o código de pareamento e digite-o no agente durante a instalação (uso único).

{% include "partials/icon.html" with name="arrow-left" class="h-4 w-4" %} Configuração de impressão

Precisa instalar na máquina da loja?

Baixe o Print Agent para Windows (executável único, sem instalação). No primeiro uso ele pede o código de pareamento desta tela, detecta as impressoras conectadas e se configura sozinho — imprime comprovantes e etiquetas automaticamente quando a impressora estiver ligada.
