# Ajustes no UI/UX

1. **Leitura compulsória:** `agents.md`.
2. **Verificação do tenant:** Antes de qualquer `Model.objects.get()`, confirmar se existe filtro por `tenant`.
3. **Django Admin:** Todo novo model deve ser registrado no admin com list_display e filters.
4. **Commit:** Usar Conventional Commits.

1. O sidebar esta branco, precisa ser um azul para destacar o menu;
2. A página inicial do dashboard esta muito simples, vamos estiliza-la um pouco, segue o prompt/context desse item (execute item por item, sem pular etapas):

    Implemente a **tela inicial do sistema PDV**, exibida imediatamente após o login do usuário.

    A tela deve seguir fielmente o padrão visual das demais telas já implementadas no sistema: **moderna, minimalista, profissional, limpa e consistente com um software comercial de PDV/ERP**.

    Não transforme essa tela em um dashboard cheio de indicadores. A tela inicial deve ser propositalmente simples, funcionando como uma **home/welcome screen** para o operador.

    ---

    # 1. Objetivo da tela

    Após o login, o usuário deve ser direcionado para uma tela de boas-vindas.

    O objetivo é apresentar:

    * uma mensagem de boas-vindas;
    * uma breve orientação sobre o sistema;
    * a data atual;
    * uma mensagem positiva para o dia;
    * a identidade visual da empresa através de uma marca d'água;
    * a logo da empresa no canto inferior direito.

    Não adicionar gráficos, cards financeiros, tabelas ou indicadores nessa tela.

    A tela deve transmitir sensação de sistema organizado e profissional.

    ---

    # 4. Topbar

    Criar uma barra superior branca.

    Elementos:

    ### Esquerda

    Botão hamburger/menu.

    ### Centro/esquerda

    Campo de busca:

    ```text

    ```

    Com:

    * ícone de lupa;
    * atalho `F2` no lado direito;
    * borda cinza clara;
    * fundo branco;
    * border-radius;
    * altura consistente com as outras telas.

    ### Direita

    Avatar do operador.

    Exibir:

    ```text

    Caixa 01
    ```

    Adicionar os controles padrão da aplicação:

    * bloquear;
    * minimizar;
    * maximizar;
    * fechar.

    Manter o mesmo espaçamento e estilo das demais telas.

    # 5. Área principal

    O conteúdo principal deve ocupar todo o espaço restante.

    Fundo:

    ```text

    ```

    ou equivalente ao background já utilizado no projeto.

    Não utilizar uma grande quantidade de cards.

    A composição deve ser **minimalista e bastante espaçosa**.

    # 6. Mensagem de boas-vindas

    Posicionar o bloco principal aproximadamente no centro-esquerda da área de conteúdo.

    Utilizar:

    ### Pequeno texto superior

    ```text
    BEM-VINDO(A)! 👋
    ```

    Características:

    * uppercase;
    * peso médio;
    * tamanho aproximadamente 18px;
    * azul/cinza;
    * espaçamento entre letras discreto.

    ### Título principal

    ```text
    Bem-vindo ao seu PDV!
    ```

    Características:

    * aproximadamente 44–48px;
    * font-weight 700;
    * azul-marinho;
    * excelente contraste.

    ### Texto de apoio

    ```text
    Use o menu ao lado para acessar as funcionalidades do sistema
    e gerenciar o seu negócio com mais eficiência.
    ```

    Características:

    * aproximadamente 18px;
    * cinza azulado;
    * line-height confortável;
    * largura máxima aproximada de 600px.

    # 7. Separador

    Abaixo da mensagem, adicionar um pequeno detalhe visual:

    Uma linha horizontal azul vibrante com aproximadamente:

    ```text
    width: 70px
    height: 2px
    ```

    Não criar uma linha que atravesse toda a tela.

    ---

    # 8. Card de data

    Abaixo do separador, criar um pequeno card horizontal.

    Não deve parecer um card de dashboard.

    Ele deve funcionar apenas como uma pequena informação contextual.

    Conteúdo:

    ```text
    Hoje é 20 de maio de 2024

    Tenha um ótimo dia de trabalho!
    ```

    No lado esquerdo:

    * ícone de calendário;
    * dentro de um pequeno container azul-claro.

    O card deve ter:

    * fundo branco;
    * border;
    * border-radius aproximadamente 10–12px;
    * sombra extremamente sutil;
    * padding confortável.

    O texto principal deve ser mais escuro e o texto secundário deve ser cinza.

    # 9. Data dinâmica

    IMPORTANTE:

    Não deixar `20 de maio de 2024` fixo.

    A aplicação deve utilizar a **data atual do sistema**.

    Criar uma função/helper para formatar a data em português brasileiro.

    Exemplo:

    ```text
    Hoje é 26 de agosto de 2026
    ```

    A data deve ser atualizada automaticamente.

    Utilizar locale:

    ```text
    pt-BR
    ```

    # 11. Marca d'água de fundo

    Criar uma versão grande e extremamente discreta do símbolo principal da logo como marca d'água no background.

    A marca d'água deve aparecer principalmente no lado direito da tela.

    Características:

    * tamanho grande;
    * opacity extremamente baixa;
    * aproximadamente 3%–7%;
    * sem interferir na leitura;
    * posição absoluta;
    * parcialmente fora da área visível pode ser aceitável;
    * não deve parecer uma imagem normal;
    * deve parecer uma marca d'água institucional.

    A marca d'água deve ocupar aproximadamente:

    ```text
    40%–50% da altura disponível
    ```

    e ficar atrás do conteúdo.

    Utilizar:

    ```css
    position: absolute;
    pointer-events: none;
    user-select: none;
    opacity: 0.04;
    ```

    Ajustar a opacidade conforme necessário para manter um visual elegante.

    ---

    # 12. Logo institucional

    No canto inferior direito da área principal, posicionar a logo completa da empresa.

    A logo deve conter:

    ```text
    Ø1
    ONEMANCOMPANY
    WENDRXW
    ```

    Utilizar o asset original.

    Características:

    * tamanho aproximado: 220–280px de largura;
    * opacity aproximadamente 80%–90%;
    * posicionamento no canto inferior direito;
    * margem direita de aproximadamente 30–50px;
    * margem inferior de aproximadamente 25–40px.

    Não colocar a logo dentro de um card.

    Não colocar fundo atrás da logo.

    Ela deve simplesmente ficar sobre o background.

    ---

    # 13. Hierarquia visual

    A ordem visual deve ser:

    ```text
    1. Bem-vindo ao seu PDV!
    2. Texto explicativo
    3. Data
    4. Marca d'água
    5. Logo institucional
    ```

    A marca d'água nunca deve competir visualmente com o título.

    ---

    # 14. Responsividade

    Embora o sistema seja prioritariamente desktop, implementar comportamento adequado para diferentes larguras.

    Em telas menores:

    * reduzir o tamanho da marca d'água;
    * reduzir o tamanho da logo;
    * ajustar o posicionamento do conteúdo;
    * permitir recolhimento da sidebar;
    * manter o título legível.

    Não permitir que a marca d'água cubra textos ou controles.

    ---

    # 15. Animações

    Adicionar somente microinterações discretas.

    * pequena animação de opacity + translateY.

    Não utilizar animações exageradas.

    Não utilizar parallax.

    Não utilizar elementos flutuantes.
