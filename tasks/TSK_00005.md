## Procedimento padrão do agente (aplicar a todas as tasks)

1. **Leitura compulsória:** `agents.md`.
2. **Verificação do tenant:** Antes de qualquer `Model.objects.get()`, confirmar se existe filtro por `tenant`.
3. **Django Admin:** Todo novo model deve ser registrado no admin com list_display e filters.
4. **Commit:** Usar Conventional Commits.


## Tarefa

Implementar a Fase 5 (Inventário) do módulo de Produtos, Estoque e
Inventário (`docs/general.md`, seções 23–25):

- Models `Inventario` e `InventarioItem` por tenant.
- Status explícitos: ABERTO, EM_CONTAGEM, EM_REVISAO, FINALIZADO,
  CANCELADO — sem alterações arbitrárias após finalização.
- Fluxo: iniciar → selecionar produtos → quantidade_sistema congelada no
  início (referência do inventário, não o saldo corrente) → informar
  contagem → calcular divergência → revisar → finalizar gerando
  movimentações de ajuste via `EstoqueService` (nunca sobrescrever saldo
  sem histórico) → ou cancelar.
- Estratégia de divergência documentada no código/docs.
- Interface: `/inventarios/`, `/inventarios/novo/`,
  `/inventarios/<uuid>/`, `/inventarios/<uuid>/contagem/`,
  `/inventarios/<uuid>/finalizar/`.
- Django Admin com list_display/filters/actions.
- Testes: criação, contagem, divergência, finalização com geração de
  ajustes, cancelamento, bloqueio após finalização, isolamento
  multi-tenant.
