# Implementação do módulo de impressão de etiquetas — Elgin L42 Pro Full

1. **Leitura compulsória:** `agents.md`.
2. **Verificação do tenant:** Antes de qualquer `Model.objects.get()`, confirmar se existe filtro por `tenant`.
3. **Django Admin:** Todo novo model deve ser registrado no admin com list_display e filters.
4. **Commit:** Usar Conventional Commits.

Implemente no sistema um módulo completo para **seleção, visualização e impressão de etiquetas de produtos**, utilizando uma **Elgin L42 Pro Full** com rolo de etiquetas de **duas etiquetas lado a lado por fileira**.

A implementação deve considerar tanto a interface do usuário quanto a lógica de impressão física.

---

# 1. Busca de produtos

Na tela de **Cadastro de Produtos**, especificamente na listagem de produtos, adicionar uma opção de **buscar/pesquisar produtos**.

## Requisitos

Adicionar um campo de pesquisa claramente identificado, por exemplo:

**"Buscar produto..."**

A busca deve permitir localizar produtos por:

* Nome;
* Código do produto;
* Código de barras;
* Outros identificadores já existentes no cadastro, quando aplicável.

A pesquisa deve atualizar a listagem de forma rápida e sem necessidade de recarregar toda a página.

Caso nenhum produto seja encontrado, exibir uma mensagem informativa:

**"Nenhum produto encontrado."**

---

# 2. Seleção de produtos para impressão

Na listagem de produtos, adicionar uma forma de selecionar produtos individualmente para impressão de etiquetas.

Cada produto deve possuir:

* Checkbox de seleção;
* Informações básicas do produto;
* Código de barras;
* Nome/descrição;
* Ação para adicionar à impressão.

Também deve existir uma opção de:

**"Selecionar todos"**

quando apropriado.

O usuário deve poder selecionar:

* Apenas 1 produto;
* 2 produtos;
* Vários produtos;
* Todos os produtos encontrados na pesquisa.

Após selecionar produtos, disponibilizar uma ação claramente identificada:

**"Imprimir etiquetas"**

ou

**"Preparar impressão"**

---

# 3. Quantidade de etiquetas

A interface deve permitir definir a quantidade de etiquetas de cada produto que será impressa.

Exemplo:

| Produto   | Código       | Quantidade |
| --------- | ------------ | ---------: |
| Produto A | 789000000001 |          3 |
| Produto B | 789000000002 |          2 |

Se o sistema já possuir uma quantidade padrão ou lógica de quantidade de impressão, reutilizá-la.

A quantidade deve ser configurável individualmente para cada produto selecionado.

---

# 4. Regra fundamental da bobina

A impressora utiliza uma bobina com:

**2 etiquetas lado a lado em cada fileira física.**

Portanto, o sistema deve tratar cada fileira física como uma unidade de impressão composta por:

```text
┌────────────────────┬────────────────────┐
│                    │                    │
│     ETIQUETA 1     │     ETIQUETA 2     │
│                    │                    │
└────────────────────┴────────────────────┘
             1 FILEIRA
```

As duas etiquetas pertencem à mesma fileira física.

---

# 5. Regra para impressão de apenas um produto

Esta é uma regra fundamental e deve ser refletida tanto na interface quanto no preview.

Se o usuário selecionar apenas **um produto para imprimir uma etiqueta**, o sistema deve deixar claro que **uma fileira inteira da bobina será utilizada**.

Exemplo:

```text
┌────────────────────┬────────────────────┐
│                    │                    │
│     PRODUTO A      │      VAZIA         │
│   CÓDIGO DE BARRAS │                    │
│                    │                    │
└────────────────────┴────────────────────┘
```

A segunda etiqueta da fileira **não deve receber outro produto automaticamente**.

Também não deve haver impressão de conteúdo na segunda etiqueta.

Entretanto, a impressora deverá avançar para a próxima fileira, pois o rolo físico trabalha em fileiras de duas etiquetas.

## Informação obrigatória ao usuário

Quando apenas um produto for selecionado, exibir uma informação visual antes da impressão:

> **Atenção: esta impressão utilizará uma fileira da bobina. A segunda etiqueta da fileira ficará em branco.**

Essa informação deve aparecer no preview e/ou imediatamente antes da confirmação da impressão.

---

# 6. Regra para múltiplos produtos

Quando houver vários produtos selecionados, preencher as posições da bobina sequencialmente, da esquerda para a direita.

Exemplo com 2 produtos:

```text
┌────────────────────┬────────────────────┐
│     PRODUTO A      │     PRODUTO B      │
│   CÓDIGO DE BARRAS │   CÓDIGO DE BARRAS │
└────────────────────┴────────────────────┘
```

Exemplo com 3 produtos:

```text
┌────────────────────┬────────────────────┐
│     PRODUTO A      │     PRODUTO B      │
│   CÓDIGO DE BARRAS │   CÓDIGO DE BARRAS │
└────────────────────┴────────────────────┘

┌────────────────────┬────────────────────┐
│     PRODUTO C      │       VAZIA        │
│   CÓDIGO DE BARRAS │                    │
└────────────────────┴────────────────────┘
```

Exemplo com 4 produtos:

```text
┌────────────────────┬────────────────────┐
│     PRODUTO A      │     PRODUTO B      │
└────────────────────┴────────────────────┘

┌────────────────────┬────────────────────┐
│     PRODUTO C      │     PRODUTO D      │
└────────────────────┴────────────────────┘
```

A ordem deve ser previsível e seguir a ordem apresentada na lista de impressão.

---

# 7. Quantidades e agrupamento

A lógica deve considerar a quantidade solicitada de cada produto.

Exemplo:

Produto A = 3 etiquetas
Produto B = 1 etiqueta

A sequência física deverá ser:

```text
FILEIRA 1
┌────────────────────┬────────────────────┐
│     PRODUTO A      │     PRODUTO A      │
└────────────────────┴────────────────────┘

FILEIRA 2
┌────────────────────┬────────────────────┐
│     PRODUTO A      │     PRODUTO B      │
└────────────────────┴────────────────────┘
```

Não preencher posições automaticamente de maneira que altere a quantidade solicitada.

A lógica deve trabalhar com uma sequência linear de etiquetas e posteriormente agrupá-las em pares:

```text
[Etiqueta 1] [Etiqueta 2]
[Etiqueta 3] [Etiqueta 4]
[Etiqueta 5] [Etiqueta 6]
...
```

Quando existir uma quantidade ímpar de etiquetas, a última posição deve permanecer vazia.

---

# 8. Preview de impressão

Criar um **preview de impressão próprio do sistema**.

Não depender exclusivamente do preview nativo do navegador ou do sistema operacional.

O preview deve representar visualmente a bobina exatamente como ela será utilizada.

O usuário deverá visualizar:

* As duas etiquetas por fileira;
* Nome do produto;
* Código de barras;
* Texto associado ao código de barras, se configurado;
* Etiquetas vazias;
* Quantidade total de fileiras;
* Ordem de impressão.

Exemplo:

```text
                 PRÉ-VISUALIZAÇÃO

┌──────────────────────┬──────────────────────┐
│                      │                      │
│      PRODUTO A       │      PRODUTO B       │
│                      │                      │
│   ███████████████    │   ███████████████    │
│   789000000001       │   789000000002       │
│                      │                      │
└──────────────────────┴──────────────────────┘

┌──────────────────────┬──────────────────────┐
│                      │                      │
│      PRODUTO C       │        VAZIA         │
│                      │                      │
│   ███████████████    │                      │
│   789000000003       │                      │
│                      │                      │
└──────────────────────┴──────────────────────┘
```

O preview deve ser atualizado automaticamente quando o usuário:

* Adicionar produto;
* Remover produto;
* Alterar quantidade;
* Alterar a ordem;
* Alterar dados relevantes da etiqueta.

---

# 9. Informações no preview

No topo do preview, mostrar um resumo:

**Produtos selecionados:** X
**Total de etiquetas:** X
**Total de fileiras utilizadas:** X
**Posições vazias:** X

Exemplo:

> Produtos selecionados: 3
> Total de etiquetas: 5
> Fileiras utilizadas: 3
> Posições vazias: 1

Isso permite ao usuário saber exatamente quanto da bobina será consumido.

---

# 10. Aviso para posições vazias

Sempre que a quantidade total de etiquetas for ímpar, informar:

> **A última fileira possui uma posição vazia. Essa etiqueta não será impressa.**

Esse comportamento deve ser visualizado claramente no preview.

---

# 11. Layout da etiqueta

O layout deve ser configurável para a Elgin L42 Pro Full.

A bobina deve ser tratada como duas colunas:

```text
                 LARGURA TOTAL DO ROLO

┌────────────────────────┬────────────────────────┐
│                        │                        │
│       COLUNA 1         │       COLUNA 2         │
│                        │                        │
│                        │                        │
└────────────────────────┴────────────────────────┘
```

Não considerar as duas etiquetas como uma única etiqueta larga.

Cada etiqueta deve possuir sua própria área de impressão.

---

# 12. Dimensões

Não assumir dimensões que não tenham sido informadas.

O sistema deve possuir configurações para:

* Largura de cada etiqueta;
* Altura de cada etiqueta;
* Gap horizontal entre etiquetas;
* Gap vertical entre fileiras;
* Margem esquerda;
* Margem superior;
* Offset horizontal;
* Offset vertical;
* DPI da impressora.

A Elgin L42 Pro Full deve ser configurada considerando sua resolução de **203 DPI**.

As dimensões devem ser convertidas corretamente para a unidade utilizada pelo protocolo/driver de impressão.

---

# 13. Código de barras

O código de barras deve ser renderizado dentro dos limites da etiqueta.

Regras:

* Nunca ultrapassar a área da etiqueta;
* Não atravessar o espaço entre as duas etiquetas;
* Não cortar o código;
* Manter margem de segurança;
* Permitir leitura por leitor convencional;
* Exibir o valor textual abaixo do código quando essa opção estiver habilitada.

O tipo de código de barras deve respeitar o padrão já utilizado pelo sistema. Caso o sistema ainda não possua um padrão definido, utilizar um formato adequado ao conteúdo do código e permitir configuração futura.

---

# 14. Tela de confirmação

Antes de enviar a impressão para a impressora, apresentar uma tela de confirmação.

Exemplo:

**Confirmar impressão**

```text
Produtos: 5
Etiquetas: 12
Fileiras: 6
Posições vazias: 0

Impressora:
Elgin L42 Pro Full

[ Cancelar ]     [ Imprimir ]
```

Se houver posição vazia:

```text
⚠ Atenção

A última fileira possui uma etiqueta vazia.
Serão utilizadas 6 fileiras da bobina.

[ Voltar ]     [ Confirmar impressão ]
```

---

# 15. Impressão

Após a confirmação, enviar a impressão respeitando exatamente a organização apresentada no preview.

A impressão deve:

1. Posicionar corretamente a primeira etiqueta;
2. Imprimir a coluna esquerda;
3. Imprimir a coluna direita quando houver conteúdo;
4. Deixar a posição vazia sem conteúdo;
5. Avançar corretamente para a próxima fileira;
6. Repetir até completar todas as etiquetas.

Não permitir que uma impressão seja deslocada para a etiqueta seguinte.

---

# 16. Calibração

Disponibilizar, se possível, uma opção de:

**"Calibrar etiquetas"**

para auxiliar na configuração do sensor da impressora.

Após a calibração, realizar uma impressão de teste para validar:

* Início da etiqueta;
* Final da etiqueta;
* Distância entre colunas;
* Distância entre fileiras;
* Posicionamento do código de barras;
* Offset horizontal;
* Offset vertical.

---

# 17. Arquitetura da funcionalidade

Separar a lógica de:

**Seleção → Preparação → Organização → Preview → Impressão**

A lógica de organização deve primeiro gerar uma lista linear de etiquetas:

```text
[
  Produto A,
  Produto A,
  Produto B,
  Produto C,
  Produto C
]
```

Depois transformar essa lista em fileiras de duas posições:

```text
[
  [Produto A, Produto A],
  [Produto B, Produto C],
  [Produto C, vazio]
]
```

O preview e o módulo de impressão devem utilizar **a mesma estrutura de dados**, garantindo que aquilo que aparece no preview seja exatamente aquilo que será enviado para a impressora.

---

# 18. Regra de consistência

O preview é a referência visual da impressão.

**Se o usuário visualizar uma determinada disposição das etiquetas no preview, a impressão física deverá reproduzir exatamente essa disposição.**

Não implementar uma lógica diferente para o preview e outra para a impressão.

A implementação somente deve ser considerada concluída quando todos os seguintes casos funcionarem corretamente:

* [ ] Buscar um produto pelo nome.
* [ ] Buscar um produto pelo código de barras.
* [ ] Selecionar um produto.
* [ ] Selecionar vários produtos.
* [ ] Selecionar todos os produtos encontrados.
* [ ] Definir quantidade individual por produto.
* [ ] Visualizar preview antes da impressão.
* [ ] O preview mostrar duas etiquetas por fileira.
* [ ] Uma única etiqueta ocupar apenas uma posição da fileira.
* [ ] A segunda posição permanecer explicitamente vazia.
* [ ] O usuário ser avisado de que uma fileira será consumida mesmo quando houver apenas uma etiqueta.
* [ ] Duas etiquetas preencherem uma única fileira.
* [ ] Três etiquetas ocuparem duas fileiras.
* [ ] Quatro etiquetas ocuparem duas fileiras.
* [ ] Quantidades maiores serem agrupadas corretamente.
* [ ] Quantidade ímpar gerar uma última posição vazia.
* [ ] O preview mostrar a mesma organização que será impressa.
* [ ] O código de barras permanecer dentro da etiqueta.
* [ ] A impressão respeitar as duas colunas físicas.
* [ ] O avanço vertical ocorrer corretamente entre as fileiras.
* [ ] Não haver impressão atravessando a divisão entre as etiquetas.
* [ ] A configuração permitir ajuste de dimensões e offsets.
* [ ] A impressora Elgin L42 Pro Full ser utilizada corretamente.
* [ ] Uma impressão de teste permitir validar o alinhamento físico.

## Regra principal

**Nunca esquecer que o rolo físico possui duas etiquetas por fileira.**

Uma etiqueta selecionada = uma posição utilizada + uma posição vazia.

Duas etiquetas selecionadas = uma fileira completa.

Três etiquetas selecionadas = duas fileiras, sendo a segunda fileira parcialmente preenchida.

O sistema deve deixar essa regra evidente para o usuário através do **preview e dos avisos da tela de confirmação**.
