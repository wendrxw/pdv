## Itens da task

### 1. Esqueleto do pacote `pdv-desktop/` (novo, sem tocar no Django)

Estrutura conforme `docs/migracao-desktop.md` §22:

```
pdv-desktop/
├── pyproject.toml          # pywebview>=5, pywin32 (Windows), hatchling
├── launcher.py             # entry point PyInstaller (padrão do print-agent)
├── README.md
├── src/pdv_desktop/
│   ├── __init__.py         # __version__
│   ├── main.py             # bootstrap (Fase 1 implementa a janela)
│   ├── config.py           # Config (env PDV_DESKTOP_* + ~/.pdv-desktop/config.json 0600)
│   ├── window.py           # stub (Fase 1)
│   ├── tray.py             # stub (Fase 3)
│   ├── offline.html        # tela de erro/offline (sem dependência externa)
│   ├── session.py          # stub (Fase 2)
│   ├── updater.py          # stub (Fase 14)
│   └── print_embedded.py   # stub (Fase 10)
└── tests/
    ├── test_bootstrap.py
    ├── test_updater.py
    ├── test_bridge.py
    └── test_print_embedded.py
```

Convenções: mesmo estilo do `local-print-agent` (unittest, launcher na raiz, hatchling,
sem dependências pesadas além do necessário).

### 2. Build estático do Tailwind (pré-requisito das fases desktop)

- Extrair a config inline de `frontend/templates/base.html` para
  `frontend/static/css/tailwind.config.js` (idêntica — navy/brand, font Inter).
- Criar `frontend/static/css/input.css` (`@tailwind base/components/utilities`).
- Criar `frontend/build-tailwind.sh`: baixa o CLI standalone **v3.4.17** (mesma geração do
  Play CDN atual — evita diferenças visuais do v4) e compila com content scanning de
  `apps/**/templates/**/*.html`, `frontend/templates/**/*.html` **e `apps/**/*.py`**
  (classes de forms em constantes Python, ex. `INPUT_CLASS`).
- Servir a fonte Inter localmente (`frontend/static/fonts/inter/` + `css/fonts.css`),
  removendo o Google Fonts.
- Atualizar `base.html`: remover CDN/inline config/Google Fonts; linkar
  `{% static 'css/tailwind.css' %}` e `{% static 'css/fonts.css' %}` com cache-busting
  via `versao_deploy`.
- Binário do CLI fica em `frontend/.tools/` (git-ignored).

### 3. Verificação

- `uv run python -m unittest` dentro de `pdv-desktop/` (com `PYTHONPATH=src`) — verde.
- `uv run ruff check` no novo pacote.
- `uv run python manage.py test` — 456 testes continuam verdes (nenhuma mudança em apps/).
- `uv run python manage.py check`.
- Inspeção visual das páginas principais no navegador (login, dashboard, PDV, financeiro)
  para confirmar que o CSS compilado é idêntico ao CDN.
